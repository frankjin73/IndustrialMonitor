#帧格式设计

帧头  : 0xAA 0x55              (2 字节, 大端)
长度  : 数据区字节数           (1 字节, 0~255)
命令字：1字节                  (0x01 = 传感器数据上报)
数据区：
	时间戳    : 4 字节  uint32  大端 (Unix 秒)
    设备 ID   : 1 字节  uint8
    传感器 ID : 1 字节  uint8
    数据类型  : 1 字节  uint8  (0x01 = 温度 int16×100)
    数值      : 2 字节  int16   大端
	
校验  ：CRC16-MODBUS         (2 字节, 小端)
CRC 计算范围: 帧头 + 长度 + 命令字 + 数据区 (不含 CRC 本身)
